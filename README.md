# Q'mem Baltna

Q'mem Baltna is a premium Ethiopian and Eritrean spice brand focused on authentic Habesha flavors, export-ready packaging, and global shipping.

## What this project includes

- Premium spice storefront experience for online orders
- Multi-currency and bilingual interface
- Product catalog, cart, checkout, and rewards flow
- SEO-friendly landing page structure for organic discovery and AI search visibility

## Local development

Prerequisites:

- Node.js 18+

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Production notes

- Configure the live domain and canonical URL in the HTML metadata before deployment.
- Add your real sitemap and social image assets to the public directory if needed.
- Keep pricing, contact details, and business information aligned with your latest storefront content.
